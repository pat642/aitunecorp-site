# AI TUNE Corp — site

Site vitrine statique d’AI TUNE Corp, déployé sur `aitunecorp.fr`.

## Fichiers principaux

- `index.html` — accueil en français.
- `es/index.html` — accueil en espagnol.
- `ceso/index.html` — démonstration CESO.
- `console/index.html` — démonstration de console.
- `magazine/` — contenus éditoriaux et guide SEO.
- `robots.txt`, `sitemap.xml`, `.htaccess` — fichiers de publication.

Les prototypes publics ne doivent recevoir aucune donnée client réelle. Ne pas ajouter de mots de passe, clés, jetons de déploiement ou données personnelles au dépôt.

## Travailler à deux

1. Créer une branche pour chaque modification.
2. Décrire la modification dans une pull request et vérifier l’aperçu sur le site de test ou en local.
3. Relire ensemble le contenu et le diff avant de fusionner.
4. Déployer seulement après validation, depuis l’espace OVH associé au multisite `aitunecorp.fr`, avec l’action **Deploy Git**.
5. Vérifier le site en ligne après le déploiement.

Un accès au dépôt GitHub autorise la modification du code. Il ne donne pas automatiquement accès au projet de chat partagé, à OVH, aux e-mails ni aux comptes de domaine. Attribuer séparément chaque accès nécessaire et utiliser des comptes individuels ; ne jamais partager un mot de passe ou un code de connexion.

Pour que Manu puisse poursuivre une conversation avec son contexte et ses instructions, il doit aussi être ajouté au projet ChatGPT AI TUNE — Pat & Manu avec le rôle **Can edit**. L’accès au dépôt, à lui seul, ne partage pas ce projet ni ses conversations.
